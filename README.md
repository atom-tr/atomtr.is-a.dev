# atomtr.dev

Personal site of Thai Tran (atomtr) — an ASCII-art "Atom" that holds the atom as you scroll.
Astro · Three.js · GSAP.

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # static site in dist/
```

Deploy: Cloudflare Pages — build command `pnpm build`, output directory `dist`.

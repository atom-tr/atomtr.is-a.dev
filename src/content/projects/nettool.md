This project description showcases a web-based tool designed for the Network Department to streamline network management with advanced features like customer bandwidth and device configuration management.

### Key Functionalities

- **Customer Bandwidth Management**
  - Search and view bandwidth information
  - Adjust and schedule bandwidth changes
- **Device Interface Configuration Management**
  - Lookup configuration details and verify device settings

- **Role**: Full Stack Developer and System Architect
- **Team Size**: 1 Developer, 1 Project Manager
- **Tech Stack**: Redis, MySQL, Celery, Django, Docker, JavaScript, HTML5, CSS3

### Key Responsibilities

1. **Frontend Development:** Responsive interface using modern web technologies.
2. **Backend Development:** Backend services and APIs using Django, integrating with network tools.
3. **Database Management:** Relational (MySQL) and non-relational (Redis) data persistence.
4. **Testing & Performance:** End-to-end testing and performance tuning for high network load.
5. **Infrastructure & Security:** Hardening access control and role-based permissions.
